----Gym Management System – Flask Website----

- Project Description:
This project is a basic Gym Management System website developed using Flask, HTML, and CSS. The website provides information about the gym, its mission, facilities, and membership plans in a clean and user-friendly layout.

- Purpose of the Project
The purpose of this project is to demonstrate how a simple web application can be built using the Flask framework. It helps in understanding routing, templates, and basic front-end design using HTML and CSS.

- Features

• Home page with gym introduction and highlights
• About Us page describing the gym’s mission and environment
• Membership page displaying different membership plans
• Clean and professional user interface

- Technologies Used

• Python (Flask Framework)
• HTML
• CSS

- Folder Structure

• app.py – Main Flask application file
• templates/ – Contains all HTML files
• static/ – Contains CSS file
